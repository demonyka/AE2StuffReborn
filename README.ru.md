# AE2 Stuff Reforged (Minecraft 1.16.5)

[English](README.md)

Порт мода [AE2 Stuff](https://github.com/bdew-minecraft/ae2stuff) (автор bdew, MIT) с ветки `mc1.12`, версия 0.7.0.
Оригинал написан на Scala и зависел от bdlib. Порт написан на Java и требует только Forge и Applied Energistics 2.

| Что | Версия |
| --- | --- |
| Minecraft | 1.16.5 |
| Forge | 36.1.10 и новее, проверено на 36.2.42 |
| Applied Energistics 2 | 8.4.7 и новее в ветке 8.x, проверено на 8.4.7 |
| JEI | необязательно, проверено на 7.7.1.153 и 7.8.1.1018 |
| Hwyla | необязательно, проверено на 1.10.11-B78_1.16.2 |

Предметы и трубы работают через стандартный `IItemHandler`. Проверены воронки, шины и интерфейсы AE2, Mekanism 10.1.2 и Pretty Pipes 1.9.8.

## Содержимое

Блоки: Pattern Encoder, Crystal Growth Chamber, Advanced Inscriber, Wireless Connector.
Предметы: Wireless Setup Kit, Network Visualisation Tool.

Идентификаторы, рецепты, значения настроек, NBT-ключи и переводы сохранены.

## Сборка

Нужна JDK 8.

```
JAVA_HOME=<путь к JDK 8> ./gradlew build
```

Готовый мод появится в `build/libs/AE2StuffReforged-1.16.5-<версия>.jar`. Для запуска в среде разработки есть задачи `runClient` и `runServer`.

## Что изменилось из-за Minecraft и Forge

- `tuning.cfg` заменён на `config/ae2stuff-common.toml` с теми же параметрами.
- `recipes.cfg` заменён на JSON-рецепты. Рецепты переопределяются датапаком, папки `overrides` больше нет.
- Измерение в привязке инструментов хранится как имя, а не как число.
- Подсказки через Waila работают с Hwyla для 1.16.

## Что изменилось из-за AE2

| AE2 1.12 (rv5/rv6) | AE2 8.4.7 | Решение в порту |
| --- | --- | --- |
| `AEApi.instance()` | класс удалён | `appeng.core.Api.instance()` |
| Реестр `IInscriberRegistry` | рецепты стали ванильным типом рецепта | `InscriberRecipes.getRecipes(world)` и проверка через `Ingredient` |
| Шаблон хранит только предметы | шаблон крафта ссылается на id рецепта | кодирование через `ICraftingHelper.encodeCraftingPattern` |
| Один предмет семени | три отдельных предмета семян | определение через `IGrowableCrystal` |
| Панели апгрейдов в `inscriber.png` и `mac.png` | панели в `extra_panels.png`, `mac.png` удалён | панели рисуются по схеме `UpgradesPanel` из AE2 |
| Ключ вращает любой блок | ключ вращает только `AEBaseBlock` | Encoder вращается сам при клике ключом |
| Ключ пропускает Shift+ПКМ к блоку | `doesSneakBypassUse` у ключа убран | обработчик `WrenchInteractionHandler` |
| `IGuiItem.getGuiObject(is, world, pos)` | добавлен номер слота инвентаря | вызов обновлён |
| `Upgrades.registerItem(ItemStack, int)` | принимает `IItemProvider` | вызов обновлён |

## Исправлено по сравнению с оригиналом

Для многопользовательских серверов:

- Через GUI машин и тулбокс сетевого инструмента больше нельзя дюпнуть или потерять предметы.
- При нарушении безопасности сети машина выпадает вместе с содержимым.
- Беспроводной коннектор, набор настройки и визуализатор не загружают чанки, а выгруженная связь не тратит энергию.
- Разборка ключом генерирует событие ломания блока, его видят моды приватов.
- Перенос рецепта из JEI укладывается в один сетевой пакет даже для рецептов с огромными тегами.
- Pattern Encoder учитывает изменения рецептов через `/reload`, CraftTweaker и KubeJS.

## Сохранённые особенности оригинала

Порт повторяет оригинал, поэтому эти особенности оставлены намеренно:

- Advanced Inscriber учитывает порядок верхней и нижней формы, хотя обычный инскрайбер AE2 разрешает их менять местами.
- Advanced Inscriber не поддерживает именные формы.
- Если второй коннектор пропал, первый сохраняет привязку к его координатам.
- Формы со снятым замком автоматика может забрать только во время работы машины, хотя подсказка в GUI говорит об обратном.
- Машина без запаса энергии может стартовать с задержкой до 100 тиков.

## Совместимость

Проверено на Forge 36.2.42 с AE2 8.4.7: JEI 7.7.1 и 7.8.1, Hwyla 1.10.11, CraftTweaker 7.1.2 и KubeJS 1605.3.19 (добавление и удаление рецептов крафта и инскрайбера, `/reload`), датапаки, Mekanism 10.1.2 и Pretty Pipes 1.9.8.
